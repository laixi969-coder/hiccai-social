# 勘察手册：怎么捞出真实的势

阶段 0 专用。这一步的工作量决定整个方案的上限：喂进去一份品牌 brief，只会还回一份好看的废话；喂进去三百条差评，才可能捞出一个还没被命名的词。

## 唯一的识别信号

**私下大量抱怨，公开场合没有标准说法。**

具体表现（这三条都是"缺词"的证据，见到就记下来）：

1. 评论区里那种很长、很具体、点赞很高、但表达磕磕绊绊的留言——**磕巴就是缺词**
2. 一个圈子里要靠一长串话才能解释清楚的共同处境
3. 大家反复用比喻和举例来说明的事——**说不清才打比方**

反过来：如果一个现象已经有了流行说法，命名权已被占，再进去只能借势。

## 势的三种类型

| 类型 | 特征 | 窗口 | 适用 |
|---|---|---|---|
| **热点势** | 已显性，人人可见 | 3–7 天 | 只能借势，竞争激烈，边际收益常为负 |
| **常量势** | 社会结构性情绪，永远在 | 无限 | **性价比最高**，可慢做、做深、做成年度栏目 |
| **隐性势** | 有感受，无词汇 | 未知 | 唯一能抢到命名权的类型 |

**常量势清单**（不是热点，永不过期，随时可挂靠）：代际关系、婚育压力、居住焦虑、工作意义感、身份跌落、城乡落差、学历贬值、照护负担、老去与体面、异地与漂泊、亲密关系中的沉默成本。

多数人抢热点那三天，其实最划算的是这些**可以买断的势**。热点是租来的。

## 去哪捞（按信噪比排序）

1. **自家客服/销售的投诉与拒单记录** — 信噪比最高。抱怨最集中的那一条就是行业级情绪存量所在，敢正面回应它就是冲突。
2. **差评原文**（电商、点评、应用商店）— 尤其看长差评，短差评多是情绪，长差评才有处境。
3. **小红书 / 抖音评论区** — 搜品类词，只看高赞评论里的「吐槽 + 追问」组合。用户已经替你写好了选题。
4. **搜索下拉词与相关搜索** — 反映的是不敢问人、只敢问搜索框的事。
5. **贴吧 / 豆瓣小组 / 知乎问题下的匿名回答** — 匿名区的措辞最接近真实。
6. **垂直社群聊天记录截图**（需用户提供）

## 检索动作要求

必须**实际执行检索**（联网或浏览器），不许用记忆里的印象代替。检索时：

- 用**用户自己的措辞**当关键词，不要用行业黑话。搜"房子住着憋屈"而不是"户型通风性能"。
- 至少覆盖 3 个不同来源，单一来源出的势不可信。
- 摘录时**逐字复制**，保留错别字、语气词、省略号。润色 = 销毁证据。

## 语料不足时怎么办

直接输出：

```
证据不足，无法勘察。
已有：（列出拿到了什么）
还需要：（具体列出 3–5 项，例如"该品类近 3 个月的长差评 50 条以上"）
```

**不许用推测填补，不许先给一个"参考方向"再让用户补证据。** 一旦允许脑补，输出的必然是训练数据里的过期刻板印象（如"996 的疲惫""付完房租不敢点外卖"），这些词的势早已耗尽。

## 输出格式

每个候选势：

```
势 N：（一句话描述这个处境，用大白话，不用营销词）
类型：热点势 / 常量势 / 隐性势
原话证据：
  1. "……"（来源：xx 平台 xx 帖，赞 xxx）
  2. "……"
  3. "……"
缺词证据：磕巴 / 长句解释 / 打比方 —— 具体指出在哪一句
现有说法：（若已有流行词，写出来，说明只能借势）
```

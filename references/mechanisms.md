# 机制原型库

阶段 2 专用。

## 先分叉：这件事需要用户做事吗？

**不要默认答案是"需要"。** 传播有两条通道，成本差一个量级：

| | 通道一 · 参与型 | 通道二 · 单件型 |
|---|---|---|
| 用户要做什么 | 做点什么，产出带自己信息的东西 | **什么都不用做，只是转发** |
| 转发动机 | "我参与了" | "这个太准了/太狠了，我得给你看" |
| 成本 | 开发 + 物料 + 种子 | 一张图、一段记录、一个数 |
| 载体 | 生成器、地图、挑战 | 一张照片、一个截图、一段对话、一份文件 |

**先判断能不能走通道二。走得通就别做通道一。** 绝大多数把事件整重的错误，都源于没问这一句就直接去设计机制。

- 走通道二 → 跳到本页末尾的「单件型」，六原型不适用
- 走通道一 → 从下面六种里选，**不许自创第七种**

# 通道一：六种参与机制

**只能从这六种里选。** 不属于这六类的"创意"，基本都是自嗨。

## 通用硬门槛（六种都必须满足）

- 单人参与动作 **≤ 10 秒**，且立刻能看到自己那一份
- 输出物**携带用户自己的信息**：名字 / 城市 / 照片 / 年份 / 选择 / 数据
- 留出**可篡改的接口**：可换的字、可替的图、可续的句式
- 规则能**口头讲清**，讲不清就是没设计完

**真指标是被二次创作的次数，不是参与人数。** 只被转发不被改编的事件，生命周期是 7 天。留白比完整更有传播力。

### 当门槛与关卡 B 打架时

这两条会天然冲突：让产品成为规则（关卡 B）几乎必然抬高参与门槛（10 秒），因为不是人人手上都有你的产品。

**裁决：门槛让位于关卡 B。** 通不过关卡 B 的方案根本不该存在，门槛只是它的执行参数。

**化解办法是拆成双层，不是二选一：**

- **轻层**（人人可参与，≤10 秒，负责规模）：线上生成、投票、上传一张照片、填一个空。
- **重层**（只有产品能承担，负责关卡 B）：线下装置、实测数据、专属服务、物理能力的呈现。

两层必须**互为因果**，不能是两件并列的事：轻层的输出必须指向重层，重层的存在必须让轻层的结果不一样。

例：线上生成个人温差曲线（轻层，10 秒，人人可玩）→ 曲线里那段"缓冲"，指向线下洞口的 26℃ 过渡舱（重层，只有精确控温能做）。拆开任何一层，另一层都不成立。

如果拆不出双层，说明这个机制原型选错了，回到本页重选，不要靠降低关卡 B 的标准过关。

## 1. 挑战型 — 用身体动作当社交货币

规则简单到能口述，完成有难度但不高，完成即天然产生视频。

- **品牌位置**：规则的制定者或裁判，**不是**奖品提供方。
- **失败模式**：动作和品牌无关 → 事件被劫持，人人记得动作，说不出组织方。
- **检验**：这个动作换成任何品牌都能办吗？能 → 重做。

## 2. 生成器型 — 输入我的信息，输出我的作品

用户给一点点（名字、年份、一张照片、几个选项），系统返回高度个人化、构图漂亮、可直接晒的结果。

- 转发率最高、成本最低的一类。
- **成败只看一件事：输出物好不好看。** 丑一点点，链路就断。设计投入应压倒性地放在成图上。
- **失败模式**：输出物是模板套壳，用户一眼看出"每个人的都一样"。

## 3. 榜单标签型 — 给人一个身份标签

人转发的不是测试，是那句"我是 XX 型"。品牌要做的是**发明一套人们乐意认领的分类学**。

- **红线**：所有分支必须是褒义或可自嘲的中性词。出现真负面标签的那条线，转发率归零。
- **失败模式**：分类过多（超过 8 类，认领感稀释）；或分类结果与用户自我认知冲突。

## 4. 反行业型 — 公开一件同行不敢公开的事

成本构成、失败案例、内部标准、拒绝过的客户、真实退货率。**信息本身就是事件。**

- 唯一门槛是你真的敢。**做半套比不做更伤**——公开一个无关痛痒的数据，会被读成公关表演。
- **前置检查**：这条信息公开后，法务/供应链/渠道能不能扛住？扛不住就别启动。
- 这是六型里最容易通过关卡 B 的，因为信息天然专属于该品牌。

## 5. 共建型 — 一个需要很多人才能完成的作品

地图、词典、年鉴、墙、数据库。每人贡献一格，成果归所有人。

- 最慢，但沉淀最深，天然长出社群，且能把命名权攒成品牌资产。
- **关键设计**：单人贡献 10 秒内完成，且**能立刻看到自己那一格**。看不到自己，参与感归零。
- 适合与常量势配对，做成年度栏目。

## 6. 事故型 — 把一次真实的意外公开处理

出错、被质疑、被投诉，然后用超出预期的方式当众解决。**可信度最高的一类，因为无法预谋。**

- **它不能被策划，只能被准备**：提前授权一线有当场处置的权限和预算，事件才有机会发生。
- 在方案里的正确写法不是"策划一次事故"，而是"建立事故响应授权"。写成策划就是造假，一旦被识破反噬极重。

# 通道二：单件型

**一件东西，本身就是全部论据。** 一张照片、一个截图、一段对话记录、一份内部文件、一个数字。不需要参与、不需要解释、不需要点进去。

这是成本最低的一条路，也是最容易被高估难度的一条——**难的不是做出这件东西，是敢发和发得快。**

## 五道判据（全过才算成立）

1. **自明** —— 不配任何文字也能看懂。**需要超过一句话来解释的，不合格。**
2. **完整** —— 它自己就是全部论据，不需要"点进去看详情"。
3. **有缺口** —— 看完会想问一句"然后呢""真的假的"。这个缺口是转发和讨论的动力，全说满了就没人转。
4. **可截** —— 能被截屏、能脱离原发布环境独立活着。**带水印、带二维码、要滑动才完整的，全死。**
5. **有具体的人或具体的数** —— 不是概念，不是主张。

## 六类可用的单件物

| 类型 | 说明 |
|---|---|
| **对比图** | 前/后、这边/那边、应该/实际。一眼看完 |
| **真实文件或数据截图** | 内部标准、实测数据、失败率——反行业型的最小实现 |
| **一段真实对话** | 客服记录、师傅群聊、投诉原文（**必须脱敏且当事人授权**） |
| **一个数字** | 一句话 + 一个数。"我们今年拒收了 X 台" |
| **一个动作的照片** | 一个人在做一件"本不该他做"的事 |
| **一份手写的东西** | 手写在打印时代自带真实感 |

## 关卡 B 在这里更难过

一张图极易被剥离品牌——转到第三层就没人知道是谁发的了。

**唯一解法：品牌必须是画面里的主体或那个动作的执行者，不能只是角落的签名。**

- ✗ 一张高温的城市照片 + 品牌 logo → 剥离即无关
- ✓ 一张自家安装师傅在 43 度屋顶上作业的照片 → 那个人穿着你的工服，是你的员工，剥不掉

## 单件型不能被策划，只能被捕捉

和事故型同源。**你无法坐在办公室里设计出一张真实的照片。**

所以单件型的重层不是物料，是**捕捉与放行的速度**：

- **捕捉**：一线（安装师傅、客服、门店、工程师）随手拍、随手存的习惯与通道
- **放行**：**从拍到发不超过 24 小时的直发授权**

走传统审批流程的单件型必死——一线拍到，报上去，三天后过审，热度早没了。**没有直发授权就不要选这条通道**，选了也发不出去。

## 执行：不需要作战表

通道二不适用四阶段作战表，也不需要种子。它只需要三件事：

1. 一线的捕捉习惯（长期建设，非项目制）
2. 24 小时直发授权（含谁能拍板、什么可以不过法务）
3. 发出后 2 小时内的响应值守

**没火就是没火，不要补救、不要投放、不要二次解读。** 单件型的成本低到可以承受高失败率——这正是它的优势。一个月发十条，一条中了就够了；试图救活一条不火的，才是浪费。

## 与阶段 3 的衔接

选定原型后立即做**关卡 B**：拿掉品牌，事件是否照样成立？

成立 → 回到本页重做，直到某个规则**必须用到该产品的物理属性才能完成**。

找法：去问一线工程师/生产/施工，哪个参数是他们觉得理所当然、而营销觉得没法说的。那个参数往往就是唯一能承载机制的东西。

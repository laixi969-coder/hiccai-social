# 落地手册：从方案到真的跑起来

阶段 4 之后。**事件的死因八成在执行，不在创意。** 一份过了所有关卡的方案，仍然会死于下面几件事。

## 三条最常见的死因（先认这个，再排计划）

### 死因一：没有第一批人

**空的事件比不做还伤。** 地图上线时是 0 格、话题墙是空的、生成器没人晒——路人看一眼就走，而且再也不会回来。第一印象只有一次。

**铁律：种子必须在公开之前完成。** 地图公开那一刻要已经有 300 格，不是 0 格。这 300 格是人肉做出来的（员工、家属、社区、合作方、付费招募），**这不是作弊，是冷启动的物理成本**——但内容必须真实，是真人真事真照片，只是被组织过。

要区分清楚：组织真实的人先参与 = 冷启动；编造不存在的人 = 伪造 UGC，命中红线，一次即信用清零。

### 死因二：窗口期比审批期短

这是最容易死、也最难救的一条。热点势的窗口是 3–7 天，涉及政府资源或第三方场地的合作周期常常是 4–8 周。**方案做完时，势已经过去了。**

**所以立项第一天就要做窗口测算**，而不是等方案定稿再去谈合作：

```
势的剩余窗口 =（还能持续多久）
最短落地周期 =（合作审批 + 物料生产 + 种子铺设）
剩余窗口 < 最短落地周期 → 这个方案在这一轮做不了
```

**测算结论是"来不及"时，第一反应不是推迟，而是回头查重层选错了没有。** 绝大多数"来不及"的真实原因是选了需要外部审批的重层（关卡 C 第 5 档）。换成产品里的一个功能、一份自有数据、一支自有队伍，周期立刻从数月压到数周。先换重层，换不动了再谈推迟。

结论只有三种，必须如实告诉用户：

1. **来得及** → 排期执行
2. **来不及，但这是常量势** → 不追这一轮，按年度栏目做，明年入夏前铺完
3. **来不及，且是热点势** → **本轮放弃**。硬做出来的是一个迟到的广告

不要用"加急""特事特办"来假装第三种能变成第一种。

### 死因三：一线把它做丑了

装置做得糙、工作人员不知道这是什么、现场没人引导——用户到场那一刻，前面所有工作归零。

**判断标准：物料的美术质量和现场体验，是唯一不能省钱的地方。** 见下方预算分配。

## 四阶段作战表

### T-30 到 T-7 · 备料

| 事项 | 交付物 | 负责方 |
|---|---|---|
| 合作方审批 | 场地/资源使用书面许可 | 公关或政府关系 |
| 关卡 B 的重层落地 | 装置、数据、服务能力就位 | 产品/工程 |
| 轻层上线 | 生成器/地图/表单，压测过 | 数字/IT |
| 口径统一 | 客服话术、一线问答手册、渠道通知 | 市场 + 客服 |
| 法务预审 | 已过审表述清单 + 禁语清单 | 法务 |
| 翻车预案 | 三种翻车的处置流程与授权人 | 公关 |

**"口径统一"最常被漏掉**，后果是：用户被事件吸引，打客服电话，客服不知道有这回事。一句"没听说过"就能杀死一个案子。

### T-7 到 T-0 · 种子（不公开）

- 铺满第一批真实参与（目标量见下）
- 每一条都检查过：真人、真内容、质量能当样板
- 挑出 10–20 条最好的，作为公开后的置顶与示范
- **不发通稿、不投放、不上热搜**

种子量的经验值：**公开时的存量，要让一个陌生人滑三屏还没滑完。** 地图类 300 格起，生成器类 200 张成品，共建类 100 条。达不到就推迟公开，不要按原定日期硬上。

### T+0 到 T+72h · 点火（唯一的窗口）

前 72 小时决定生死。这期间只做三件事：

1. **公开 + 种子内容同步可见**
2. **人工响应每一条早期参与**——早期参与者被看见，会变成传播者；被忽略，会变成沉默
3. **盯一个信号：出现第一条"非邀请的自发参与"了吗？**

**72 小时止损线：** 没有出现自发参与 → **停止追加任何预算**。这时候加投放只是把钱烧在一个没有势的方案上。承认判断错了，回阶段 0，比追加预算体面得多。

出现自发参与 → 进入放大。

### T+3d 到 T+14d · 放大

- **只放大用户产出的内容，不放大品牌自己的物料。** 转用户的比发自己的有效一个量级。
- 出现二次创作（有人改成自己的版本）→ **加码**，这是唯一值得追加预算的信号。
- 只有转发没有改编 → 生命周期就是 7 天，提前准备收口，不要硬撑。
- 此时才引入媒体与 KOL，且只给他们**用户的故事**，不给品牌的通稿。

### T+14d 起 · 收口

**不收口的事件会烂尾**，而烂尾的事件明年不能再做。收口需要一个**沉淀物**：

- 共建型 → 把所有贡献做成一份实体（地图册、年鉴、展览、公开数据库）
- 生成器型 → 精选集 + 数据报告（"重庆人今夏平均倒了 X 次温差"）
- 反行业型 → 把公开的数据变成一份可年更的报告
- 挑战型 → 公布完整名单与结果，兑现所有承诺

沉淀物是明年重启的入口，也是把一次事件攒成品牌资产的唯一方式。

## 预算分配：什么必须花，什么不能花

低成本不等于平均省钱，而是**把钱压在两三个决定生死的点上**。

**必须花（省了就死）：**

1. **输出物的美术质量** —— 生成器型的成败 100% 在成图好不好看，丑一点点链路就断
2. **线下装置的物理体验** —— 关卡 B 的重层就是它，做糙了整个挂靠就假了
3. **种子的人力成本** —— 冷启动没有便宜路

**不要花（花了也没用）：**

1. **前期投放** —— 势没验证之前投放是烧钱。投放只在 T+3d 确认自发参与后才有意义
2. **发布会** —— 事件的开场是用户看到它，不是媒体听说它
3. **大 KOL 打包** —— 早期请大号会让事件显得是买的，反而抑制自发参与。KOL 放在放大期，且只讲用户故事

**货币置换**：预算实在紧，用三种非现金货币付流量成本——**时间**（做一件极耗时的事）、**尊严**（公开自己的狼狈与失败）、**情感**（替一群人说出不敢说的话）。反行业型和事故型天然属于这一类。

## 翻车预案（三种，各自的处置权必须提前指定到人）

**① 被劫持** —— 事件火了，但没人记得是谁做的。
→ 处置：不要临时加 logo（会显得急）。改为**加码重层**——把只有你能做的那部分做得更显眼，让参与者必须经过它。

**② 被质疑造假** —— "这些参与者是不是你们自己人？"
→ 处置：**当天公开种子名单与组织方式**，承认前 300 条是组织的、并说明每一条都是真人。坦白比辩解便宜得多。**这就是为什么种子绝不能伪造**——一旦有假，这条路堵死。

**③ 被扒立场不一致** —— 挖出品牌过去在同一议题上的相反言行。
→ 处置：不辩解，不删帖。承认差距，说明从什么时候开始改、改了什么。**做不到就闭嘴收口**，这一条在埋伏协议里已是四条否决之一。

三种翻车的共同纪律：**2 小时内出第一次响应**，哪怕只是"我们正在核实"。超过 6 小时，叙事就不归你了。

## 执行前的最后四问

1. 种子够不够？（不够就推迟公开，别按日期硬上）
2. 窗口和审批期算过没有？（没算过就别启动）
3. 客服和一线知不知道这件事？（不知道就先培训）
4. 三种翻车的处置人指定了没有？（没指定就别公开）

四问全过才允许 T+0。任何一项没过，如实告诉用户"还不能发"，并说明差什么。

# 枪毙关卡清单

好方案是从二十个里砍剩一个，不是一次生成三个然后挑。**没有淘汰阀的引擎只会批量生产自信的废话。**

## 关卡 A（阶段 1 出口）

见 [命名手册](naming.md)：查重 / 复述测试 / 归属测试。任一不过 → 打回阶段 0。

## 关卡 B（阶段 3 出口）

**拿掉品牌，这个事件是否照样成立？**

- 成立 → 你只是赞助商 → 打回阶段 2 重做。
- 必须用到该产品的某个物理属性才能完成 → 通过。

### 服务标准算不算"产品属性"

算，但要多过一道**复制成本测试**：

**竞品明天想抄这个机制，要付出什么？**

| 挂靠物 | 复制成本 | 判定 |
|---|---|---|
| 产品的物理参数、实测数据、专利能力 | 高，得自己重做重测 | **通过** |
| 独有的服务网络、检测规程、施工标准 | 中，有钱有网点就能跟 | **勉强通过**，须在诊断单标注并说明护城河有多深 |
| 一个承诺、一句主张、一笔赞助 | 零 | **打回**，这是冠名档伪装成机制 |

"勉强通过"必须显式写出来，不许含糊成"通过"。一份诚实的降级标注，比一份漂亮的假通过有用得多。

若同一股势下能找到物理属性的挂靠点，优先用它，服务标准只作退而求其次。

三档只交付最高档：

| 档位 | 关系 | 结果 |
|---|---|---|
| 冠名 | 品牌贴在事件上 | 人记住事件，忘了你 |
| 借势 | 品牌解读事件 | 一波流量，无沉淀 |
| **产品即机制** | 事件必须用你的产品才能发生 | 传播即体验，流量即转化 |

## 关卡 C · 自主性（与关卡 B 同时判定）

**独占性必须来自「别人没有的东西」，不是「别人做不起的东西」。**

关卡 B 有个副作用：证明"只有我们能做"最省事的办法，是造一个又大又重的物理装置。结果方案过了 B，却把启动权交到了审批人手里——**低成本病毒传播的前提是自己说了算**，一个需要盖章才能开始的方案，成本再低也不是低成本。

两问，都必须是"是"：

1. **启动权**：不求任何外部单位批准，明天就能开始吗？
2. **续命权**：任何单一外部方（政府部门、平台、场地方、合作品牌）翻脸，这件事会不会当场停摆？

任一为"否" → **打回阶段 2 换重层**，不是去推进审批。

### 重层优先级（越靠前越该选）

关卡 B 的"只有我们能做"应当由以下资产承担，**按顺序往下找，找到第一个能成立的就停**：

| 优先级 | 重层类型 | 审批依赖 | 例 |
|---|---|---|---|
| 1 | **产品里的软件/固件能力** | 无 | 一个新模式、一条新曲线、一个开关 |
| 2 | **自有数据** | 无 | 设备实测数据、售后记录、失败率 |
| 3 | **自有队伍** | 无 | 安装师傅、客服、门店店员 |
| 4 | 自有场地 | 内部审批 | 门店、体验中心、工厂 |
| 5 | ~~需外部审批的场地/公共资源~~ | **重** | 公共空间、政府设施、他方平台 |

**第 5 档默认不采用。** 只有当第 1–4 档全部试过且都不成立，且用户明确接受长周期与不确定性时，才允许提出，并必须同时给出一个第 1–4 档的可自主执行版本供对比。

第 3 档常被忽略却往往最强：**一支每天进几百万个家庭的安装队伍，是竞品拿钱也买不到的**——它既满足独占性，又完全不需要审批。

## 交付前四问（阶段 4）

把方案讲给一个**完全不认识这个品牌**的人听，讲完问：

1. **他会想参与吗？**（测参与动机）— 答不上 → 机制无效，回阶段 2。
2. **这跟哪个牌子有关系？**（测品牌绑定）— 答不上 → 关卡 B 实际没过，回阶段 2。
3. **给这个事件拟一个不含品牌名的新闻标题——写得出来吗？** 写不出 → 出不了自媒体圈，如实告知，不许瞒着交付。
4. **天花板是哪一层？** 必须明确标注：圈层刷屏 / 有破圈可能 / 不确定。**禁止标注或暗示"社会化事件"。**

这一步花不到十分钟，能砍掉八成的错误立项。

## 自嗨自检（中一条就重做）

1. 事件的主语是品牌，不是用户（"我们发起…"而不是"你可以…"）
2. 用户参与后拿不到一个可晒的、带自己信息的东西
3. 需要先理解品牌背景才能看懂事件
4. 内部开会时大家笑得很开心，但没人能一句话把它转述给外行

## 红线（命中即否决，不接受"换个说法"）

涉及公共议题必然靠近敏感区。以下不是道德姿态，是风控——这几类的翻车成本远高于收益：

- **消费真实灾难、伤亡、疾病、贫困**做转化动作
- **挑动地域、性别、民族、城乡对立**换流量
- **伪造素人故事、伪造 UGC、伪造街采**（识破率逐年上升，且一次即信用清零）
- **诱导未成年人参与**，或参与动作存在人身风险
- **煽动对具体个人或具体企业的网络暴力**
- **在事实未明时抢先表态**

红线判断优先于所有创意价值。命中时直接说"这条不能做"，并给出同一股势下的合规替代路径。

## 关于"3 个方案"

不要默认输出三个平行方案。正确做法：**内部生成多个，公开只交付通过全部关卡的**。

- 只有 1 个通过 → 就交 1 个，并说明其余被哪一关卡枪毙。
- 0 个通过 → 交「本轮无可交付方案」+ 卡点清单 + 需要补的证据。这比硬凑三个有价值得多。

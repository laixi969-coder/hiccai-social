# hiccai-social · 势能猎手

一个用于**低成本病毒式传播事件**策划的 Claude Code Skill。

它不是创意生成器，是一条**带枪毙关卡的流水线**：从真实语料里勘察情绪存量，抢占一个还没被占用的词，设计参与机制，检验品牌挂靠是否成立，标注真实的传播天花板。

---

## 为什么需要它

市面上的"病毒营销 prompt"有四个通病，这个 skill 逐条针对：

| 通病 | 本 skill 的处理 |
|---|---|
| 从品牌出发倒推创意 | 顺序倒过来：**势 → 词 → 机制 → 品牌**，品牌最后进场 |
| 洞察靠模型脑补 | 阶段 0 强制外部真实语料，**证据不足就拒绝出方案** |
| 只生产不淘汰 | 三道枪毙关卡，0 个通过就交「本轮无可交付方案」 |
| 承诺刷屏 | 强制标注天花板，**禁止承诺社会化事件** |

## 六条底层判断

1. **势不能被创造，只能被挂靠或被命名。** 品牌造不出情绪存量。
2. 借势是搭车，**命名是修路**，造势是撞墙。只做前两件。另有第四种姿势——品牌已被点名在公共议题里时，**当事人不需要标签，需要证据**。
3. **自嗨的技术定义：势能为零时的强行发力。**
4. **独占性必须来自「别人没有的东西」，不是「别人做不起的东西」。**
5. 谁给一个普遍但无名的处境起了名字，谁就拥有了这群人。
6. 社会化事件是被时机选中的，不是被策划出来的 —— 它只能被**埋伏**。

## 三个传播层级

| 层级 | 可设计性 | 本 skill 的承诺 |
|---|---|---|
| 圈层刷屏 | 高，可复制 | **承诺，可按季度重复产出** |
| 品类破圈 | 中，需时机 | 标注可能性，不承诺 |
| 社会化事件 | 几乎为零 | **禁止承诺**，改走埋伏协议 |

## 两条通道

阶段 2 的第一句话是分叉，**不要默认要做机制**：

- **通道二 · 单件型** —— 一张照片、一个截图、一段对话、一个数字。用户什么都不用做，只是转发。成本低一个量级，**走得通就别做通道一**。
- **通道一 · 参与机制** —— 六种原型：挑战型 / 生成器型 / 榜单标签型 / 反行业型 / 共建型 / 事故型。不许自创第七种。

## 三道枪毙关卡

- **关卡 A · 命名** —— 查重（有既有归属就弃）、复述测试、归属测试
- **关卡 B · 挂靠** —— 拿掉品牌，事件是否照样成立？成立即打回
- **关卡 C · 自主性** —— 不求任何人批准明天能开始吗？外部方翻脸会当场停摆吗？

关卡 C 的配套是**重层优先级**，按顺序往下找，找到第一个成立的就停：

> ① 产品里的软件/固件能力 → ② 自有数据 → ③ 自有队伍 → ④ 自有场地 → ⑤（默认禁用）需外部审批的公共资源

第 ③ 档常被忽略却往往最强：一支每天进几百万个家庭的安装队伍，竞品拿钱也买不到，还完全不用报批。

## 工作流

```
阶段 -1  资产盘点     先搞清手上有什么不用求人的东西
阶段  0  势能勘察     真实语料，逐字摘录，不许润色 —— 证据不足就停
阶段  1  抢命名       造一个能长在别人嘴里的词    → 关卡 A
阶段  2  机制设计     先分叉：单件型 or 参与机制
阶段  3  品牌挂靠     品牌最后进场               → 关卡 B + C
阶段  4  交付自检     四问 + 红线 + 天花板标注
阶段  5  落地作战     备料 → 种子 → 点火 → 放大 → 收口
```

## 交付分两层

**默认只出提案版**（人话），工作单要问才给。

内部术语（势、命名权、关卡、天花板、破圈、UGC、社交货币…）一个都不许进提案稿——**它们是手术刀，不是菜**。

提案按**提案五句**写：一个具体的人和数字 → 他在承受什么 → 点破这事一直没名字 → 揭底叫什么 → 我们要做什么。

## 安装

```bash
git clone https://github.com/laixi969-coder/hiccai-social.git ~/.claude/skills/hiccai-social
```

然后在 Claude Code 里 `/hiccai-social`，或直接说「用势能猎手看看这个项目」。

**它会先跟你要语料，要不到就拒绝出方案——这是设计如此，不是卡壳。**

## 维护

`references/naming.md` 里的**已占用词库需每季度补充一次**。这是本 skill 唯一会随时间腐坏的部分——词库越旧，输出越像在复读别人十年前抢到的名字。补充时只追加不删除（旧词的命名权不会归还）。

## 边界

本 skill 只管**事件层**：势、词、机制、挂靠、落地。标题、Hook、平台文案不在范围内，机制定稿后再另行处理。

**不许在勘察和命名阶段考虑点击率**——一旦脑子里有 CTR，就会开始为标题挑选势，那正是自嗨的起点。

## 红线

以下不是道德姿态，是风控——翻车成本远高于收益：

- 消费真实灾难、伤亡、疾病、贫困做转化动作
- 挑动地域、性别、民族、城乡对立换流量
- 伪造素人故事、伪造 UGC、伪造街采
- 诱导未成年人参与，或参与动作存在人身风险
- 煽动对具体个人或具体企业的网络暴力
- 在事实未明时抢先表态

## 来历

这套方法论不是设计出来的，是**跑出来的**。目前的六个补丁，全部来自真实跑动中暴露的失败：

| 补丁 | 触发它的失败 |
|---|---|
| 提案层 / 对外禁用词表 | 交付物全是黑话，没人听得懂 |
| 关卡 C · 自主性 | 产出了一个需要跨部门审批 3–6 周的方案 |
| 通道二 · 单件型 | 默认所有事件都要做参与机制，把成本抬高了一个量级 |
| 半命名中间态 | 词只抢到一半（处境没名字，成因是现成说法）无处归类 |
| 双层结构裁决 | 参与门槛与关卡 B 天然打架，没有裁决规则 |
| 服务型挂靠判定 | 服务标准算不算"产品属性"判不了 |

没有一个是坐着想出来的。下一批补丁也会这么来。
